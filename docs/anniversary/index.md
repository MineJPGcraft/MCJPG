# MCJPG 两周年活动专刊

## 前言

**MCJPG** 将迎来她的两周年生日，作为一个致力于Minecraft技术交流和服务器宣传的组织，这两年里始终竭诚服务于服主与玩家之间  
我们相信，经典的游戏可以团结社群，带动文化传承  
新颖的游戏更是社区的新鲜血液，而这些的前提，是人的团结  
在外界多有认为社区同质化明显，玩家交流亦式微的当下，我们希望通过MCJPG组织筹备并发起的两周年活动，让更多玩家同台，让碰撞得以发生  
当下的时代风口或许是人工智能，是人工智能带来的各种玩法；但最重要的依然是人，是沟通成就的真实创造，是互动、竞技中跨越种种壁垒的**愉悦**  
多样的游戏，允许每个人以各自舒适的方式投入和享受其中。统一的选择，保证了游戏具备高参与度。连续累计的积分，固然是一种竞争的表现方式，却也意味着每一步都值得被记录  
游戏的排名终有先后，灵魂的交流和快乐却无高下之分  
在这盛夏，让我们来一场大的

## 活动安排

### 时间与地点

活动定于2026年**8月1日**的晚上**七点半**举行，我们会在当日**七点整**于[社区群组](https://qm.qq.com/q/bAZle5ABzy)内公布小游戏服务器的连接地址和方式

### 要求

本次活动仅支持**国际版Minecraft**，支持**Java版26.2**和**最新基岩版**，虽有跨版本支持但仍建议使用正确的版本加入游戏  
本次活动**无需正版账户**，离线账户加入游戏需要注册与登录，正版账户无需这一流程。我们建议所有玩家在**活动开始前15分钟**加入游戏以便确保不会由于各种不可预见的原因导致游玩上的问题  
我们会在活动开始前于[社区群组](https://qm.qq.com/q/bAZle5ABzy)内发布调查问卷来确定活动具体的规格并对服务器进行扩容，烦请关注[社区群组](https://qm.qq.com/q/bAZle5ABzy)内信息  

### 交流频道

本次活动我们为玩家们准备了足够的交流频道，包含以下几个：  
1.[社区群组](https://qm.qq.com/q/bAZle5ABzy)为活动唯一指定交流群  
2.[Oopz 域ID:772947501](https://oopz.cn/i/i0sBkO)为唯一指定公用语音频道  
3.[Bilibili直播间](https://live.bilibili.com/1775061181)为活动唯一官方直播频道，没有时间参与活动的玩家也可以收看我们的直播

### 奖项

我们将根据每场小游戏的积分累加决出一定数量的**一等奖**、**二等奖**和**三等奖**  
没有获奖的玩家也不用灰心，我们为所有玩家准备了一份**参与奖**  
所有奖品均包含实物礼品，了解详情和领取流程请关注后续[社区群组](https://qm.qq.com/q/bAZle5ABzy)内信息

## 最后

祝大家玩的开心，这是迄今为止 **MCJPG** 举办的最为盛大的活动，愿所有人都能找到自己的乐趣！
